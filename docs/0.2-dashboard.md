# Dashboard and packet studio

The GUI is served by the management listener with `management.gui = true` and
requires the `gui` build feature. Open `/` on that listener. Assets, fonts and icons
are local; no CDN, Materialize or external font service is required.

The dashboard uses its own responsive design with light/dark themes and four views:
Devices, LG cloud, Activity and System. Devices can be searched, filtered by status
and sorted. Cards show local connectivity, driver faults and cloud bridge state.
The detail dialog exposes properties, model identity, firmware, last-seen time,
validated property commands and explicit lifecycle actions. Destructive actions
require confirmation. Scope values remain strings to preserve 64-bit identities;
commands are disabled if the captured device session changes.

LG cloud sign-in uses the existing start/complete flow. Account inventory refresh,
per-device pairing/resume/pause/unpair and external MQTT health remain distinct
operations. System offers scoped retained cleanup with confirmation. Activity keeps
at most 100 events and reports interrupted connections.

Open a device's packet studio to inspect live traffic. It offers direction filters,
pause, auto-scroll, copy, packet analysis and JSONL export. The browser retains at
most 500 records and an 8 MiB hex-string budget. Exports preserve loss markers and
use the CLI's `packet`, `clip` and `ack` record types. Buffer eviction is explicitly
recorded. Raw injection requires both the runtime switch and a confirmation;
changed device sessions require reconnecting the monitor.

`POST /api/packets/decode` accepts `hex`, optional `direction` (`fromDevice` or
`toDevice`) and optional `model_id`. It returns detailed AABB/TLV/UART analysis and
`exportText`; `GET /api/tlv/catalog` exposes the catalog. Both are available in
API-only mode. Analysis is bounded to 65,536 packet bytes and two concurrent
workers. The CLI decoder uses the same protocol analysis implementation.

Device metadata persists model ID, display model, software version and last-seen
Unix seconds. Old schema-2 records default missing fields. LG inventory and saved
device names refresh every 15 minutes. Account reconciliation pauses an enabled
bridge if its registration disappears, preserving saved registration material.
An empty inventory is confirmed by a second poll after one minute before pausing.

Validation uses local Rust integration/unit tests and browser fixtures. No live LG
account or physical appliance validation is claimed.

## Reproducing browser checks

Install Playwright outside the repository, then serve the actual assets locally:

```sh
npm install --prefix /tmp/rusthinq-gui-deps playwright
/tmp/rusthinq-gui-deps/node_modules/.bin/playwright install chromium
python3 -m http.server 8765 --bind 127.0.0.1 --directory crates/rusthinq-app/assets
```

In another terminal run:

```sh
NODE_PATH=/tmp/rusthinq-gui-deps/node_modules node scripts/check-gui.cjs
```

`GUI_TEST_URL` overrides the local server URL; `GUI_TEST_ARTIFACTS` overrides the
screenshot directory (default `/tmp/rusthinq-gui-check`). The check mocks management
responses and WebSocket traffic while loading the real HTML/CSS/JS. It checks
responsive layout, themes, search/filtering, hostile text, identity precision,
stale-session fencing, confirmation, bounded activity/traffic and capture export.
