# Selectively reused components

The 0.2 workspace has no dependency or source include into `legacy/0.1`.

- `rusthinq-protocol::{crc16,hex,tlv,tlv_catalog}` are copied pure wire utilities
  from the fixed 0.1 archive revision `2473c34683130c29ad2f07d560d15b2c94342a36`.
  Their codec tests run in the new protocol crate. IL validation is implemented
  in `rusthinq-app/assets/driver_support.rhai`, rather than these Rust utilities.
- `rusthinq-app/assets/{index.html,panel.js,monitor.html,monitor.js,dark.css,logo.svg,favicon.png}`
  originate in the same archive. API paths, scoped forget, monitor loss/results,
  injection enablement and text-only toasts have been adapted for 0.2.
- Real driver/module test fixtures retain their upstream license, pinned revision,
  and hashes in `crates/rusthinq-app/tests/fixtures/drivers/README.md`.

The new native script helpers provide generic wire/JSON codecs only. The bundled
Rhai compatibility helpers own descriptors, property state and command validation.
