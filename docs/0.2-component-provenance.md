# Selectively reused components

The 0.2 workspace has no dependency or source include into `legacy/0.1`.

- `rusthinq-protocol::{crc16,hex,tlv,tlv_catalog}` are copied pure wire utilities
  from the fixed 0.1 archive revision `2473c34683130c29ad2f07d560d15b2c94342a36`.
  Their codec tests run in the new protocol crate.
- `rusthinq-protocol::{aabb_analysis,uart_binary,decode}` selectively copy the
  archive's offline packet analysis and its unit tests. Management and CLI share
  that implementation without importing the legacy service.
- Dashboard HTML, CSS and JavaScript are rewritten for 0.2 with a shared local
  `ui.js` module. `logo.svg` and `favicon.png` retain their archive provenance.
- Real driver/module test fixtures retain their upstream license, pinned revision,
  and hashes in `crates/rusthinq-app/tests/fixtures/drivers/README.md`.

The new native script helpers provide generic wire/JSON codecs and `publish_raw` only.
No Rhai helper library is bundled; descriptors, property state and command validation
belong to the scripts (rusthinq-scripts `il_common.rhai`).

- `rusthinq-protocol::{packet_codec,mtosp,json_splitter}` selectively copy the
  archive's pure tool/setup codecs. Short-frame size conversion now rejects
  overflow; incremental JSON and tool input are bounded and poisoned on failure.
  Protocol unit tests remain in the new crate.
- `rusthinq-tools/src/bin/rusthinq-setup.rs` and `softap/whisen.rs` selectively port
  the archive's appliance bootstrap flow and Whisen helpers. The executable owns
  its OpenSSL bootstrap socket with bounded handshakes/writes; no legacy service,
  global state, dependency or source include is retained.
- `rusthinq-scripting::testing` adapts the archive's offline driver test API to the
  production compiled host. Its raw pre-start command entry exists only in the
  offline harness. Production management/MQTT commands still use Rhai validation.
  The pinned upstream revision `54292921c6edc72ea6ec901b1137845bff14e6ae`
  executes 187 test functions across 11 drivers successfully.

- `rusthinq-bridge::notifications` implements the upstream account observer contract
  (fresh account client ID, CSR certificate, regional route/CA and read-only MQTT
  subscriptions) in native Rust. Reference: rethink `30835bdb6eac3fc05c05ca824e29373bf9711d3e`,
  `util/lgcloud/monitor.ts`. Its task lifetime and bounded projections are owned by
  0.2 management; no upstream service or driver code is imported.
